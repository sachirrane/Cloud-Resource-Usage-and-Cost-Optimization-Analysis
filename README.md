# Cloud Resource Usage and Cost Optimization Analysis (MySQL)

## Project Overview
This project analyzes cloud resource usage, pricing, and utilization to compare AWS, Azure, and GCP and identify potential cost optimization opportunities using MySQL.

## Objectives
- Compare cloud resource pricing across providers.
- Analyze resource utilization and usage patterns.
- Compare virtual machine types and cloud regions.
- Identify potential opportunities to optimize cloud costs.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## SQL Concepts Used
- SELECT, WHERE, and ORDER BY
- Aggregate Functions (AVG, SUM, COUNT)
- GROUP BY and HAVING
- JOINs 

## Key Findings
- Compared average hourly prices across AWS, Azure, and GCP.
- Analyzed average resource utilization across cloud providers.
- Identified differences in pricing and utilization that may help inform cost optimization decisions.

## Project Files
- `cloud_analysis.sql` — SQL queries used for analysis.
- `SQL_Project_Report.pdf` — Project report, query outputs, and findings.
